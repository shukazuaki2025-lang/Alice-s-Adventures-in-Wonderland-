## Textures & painted materials (Round 2)
- Every texture embedded in the GLBs (`chr_alice`, `chr_sister`, `ch1_s1_bank`, …) is **generated by this repository's own code**
  (`tools/blender/lib/paint.py`, `tools/blender/alice/textures.py`, `tools/blender/world/painters.py`) — procedural gouache/watercolour
  washes, no scanned or downloaded images. License: MIT with the rest of the repo.
- **Benchmark reference (not shipped).** `https://littleprince.dev/` was used only as a *level-of-finish* yard-stick. Its artwork is
  third-party and is **not** included in the repository; only numbers derived from it (`docs/art/benchmark/littleprince-keyart-metrics.json`)
  are committed. Nothing from its characters, shapes or palette is copied.
- **Lettering on prop labels / dials** (`tools/blender/world/props_tex.py`) is set in **Liberation Serif Bold / Bold Italic** (SIL Open Font License 1.1, installed on the build machine; only
  rasterised glyphs end up inside the baked textures — the font file itself is not distributed). Falls back to DejaVu Serif Bold (Bitstream Vera licence).
